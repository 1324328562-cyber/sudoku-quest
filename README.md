# 数独百关 · Sudoku 100

100 关渐进式数独闯关游戏。纯前端、零依赖、免登录，进度存在浏览器本地，断网也能玩。

## 特点

- **100 个关卡，10 个章节**：从「起步庭院」一路打到「终焉天穹」，给定数字从 45 个严格递减到 26 个。
- **每道题都是唯一解**：生成时逐格挖洞，每挖一次都跑一遍求解器确认解仍然唯一，不会出现"有两个答案"的题。
- **难度不倒挂**：第 N 关的给定数不会多于第 N-1 关，逐关递推生成并缓存，同一关永远同一道题。
- **三星评分**：通关 1 星、全程不用提示 +1 星、在精英时间内完成 +1 星。
- **实用工具**：笔记模式、撤销、提示（每关次数有限）、检查（标红错误）、计时与暂停。
- **键盘可玩**：`1-9` 填数、方向键移动、`N` 笔记、`H` 提示、`Ctrl+Z` 撤销、`P` 暂停、`Esc` 返回。
- **移动端适配**：390px 宽度下盘面不裁切、无横向滚动。

## 本地运行

无需构建，任意静态服务器即可：

```bash
python -m http.server 8765
# 或
npx serve .
```

然后打开 `http://localhost:8765`。

## 校验关卡质量

```bash
node tools/verify-levels.js
```

会逐关检查：题面数字与解一致、解满足数独规则、解唯一、给定数曲线单调不增，并用一套**独立实现的朴素回溯求解器**交叉复核抽样关卡。当前结果：

```
给定数范围      : 26 → 45 （45 个最易，26 个最难）
给定数单调不增  : 是
全部唯一解      : 是
生成总耗时      : 14ms （平均 0.1ms/关）
问题数          : 0
```

## 技术实现

| 文件 | 作用 |
| --- | --- |
| `assets/sudoku.js` | 关卡引擎：种子随机（xmur3 + mulberry32）、位运算 MRV 求解器、唯一解挖洞、关卡元数据 |
| `assets/app.js` | 界面与交互：关卡地图、盘面渲染、输入与撤销、计时、存档、结算 |
| `assets/style.css` | 样式：纸感配色、九宫格粗线、响应式布局 |
| `tools/verify-levels.js` | 关卡质量校验脚本 |

几个实现细节：

- **可复现**：每关的随机流由 `关卡号` 派生，同一关永远生成同一道题，不需要预存 100 个盘面（整个引擎 10 KB）。
- **求解器**：用三个 9 位整数掩码记录每行/列/宫的已用数字，每步选候选最少的空格（MRV）回溯，统计到 2 个解就提前退出，刚好够判断唯一性。
- **挖洞**：前 50 关用中心对称挖洞（盘面更耐看），后 50 关随机挖洞（更难）；成对挖会让给定数低于目标时改为单格收尾，避免难度被挖过头。
- **存档**：`localStorage` 里存 `{已解锁关卡, 每关星数与最佳用时, 进行中的盘面}`，刷新或关掉浏览器都能接着玩。
